# Magma Manager v1.1.0 — Professional UI

This release redesigns administration around a branded, button-driven control centre.

## Main commands

- `$!setup` or `/setup` — full control centre
- `$!ticket-setup` or `/ticket setup` — ticket configuration
- `$!staff-apply-setup` or `/staffapply setup` — staff applications
- `$!security-setup` or `/security setup` — security and automod
- `$!invites-setup` or `/invites setup` — invite tracker
- `$!announcement-setup` or `/announcement setup` — announcement manager
- `$!dm-setup` or `/dm setup` — DM manager
- `$!backup-setup` or `/backup_setup` — backup and restore
- `$!logging-setup` or `/setup logging` — log routing

## Design

Every setup screen presents a live overview first, followed by professional buttons and selectors. The configured guild colour, footer, logo and banner are used across the dashboards.
